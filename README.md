# Al Reves Inmobiliario - MVP

MVP web estatico para publicar inmuebles en venta y arriendo, mostrar fotos, video, geolocalizacion, contacto directo por WhatsApp y captacion basica de leads.

## Editar inmuebles

Los inmuebles demo estan en `app.js`, arreglo `properties`.

Campos clave:

- `title`
- `type`
- `operation`
- `price`
- `location`
- `mapUrl`
- `videoUrl`
- `images`
- `features`
- `description`

## Probar localmente

Abrir `index.html` en el navegador o ejecutar:

```bash
npx serve .
```
